# Modern Animated Login Page 🔐

A beautiful, responsive, and interactive Login Page template designed with modern web aesthetics in mind. This interface uses modern UI/UX design trends like micro-interactions and glassmorphism, making it a perfect starting point for any web application authentication flow.

## ✨ Features
* **Fully Responsive:** Optimised for desktop, tablet, and mobile views.
* **Modern UI Elements:** Custom animations, smooth transitions, and stylized focus states.
* **JavaScript Validations:** Real-time form checks ensuring data format integrity before submission.
* **Clean Code Architecture:** Well-structured HTML5, scalable CSS3 variables, and modular JS.

## 🛠️ Built With
* **HTML5** - Structure and layout
* **CSS3** - Styling, animations, and custom variables
* **JavaScript (ES6+)** - Interactive elements and validation logic

## 📦 Project Structure
```text
Login-page/
├── index.html   # Main structural skeleton
├── style.css    # Layout rules, animations, and typography
├── script.js    # Interactive features and validation logic
└── 1.jpeg       # Background / UI visual asset
```

## 🚀 Getting Started

### Prerequisites
You only need a modern web browser (like Chrome, Firefox, or Safari) to run this locally.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd Login-page
   ```
3. Open `index.html` in your browser to view the application.

## 💡 Usage
This login component can easily be customized by updating the CSS variables inside `style.css` to match your brand's color palette. It is built to seamlessly plug into backend authentication services like Firebase, Auth0, or custom REST APIs.
